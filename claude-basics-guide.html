Section 01What is Claude?

Claude is a family of large language models (LLMs) built by Anthropic, an AI safety company founded in 2021. Claude can understand and generate text, analyze images, write code, reason through complex problems, and use tools — all through natural conversation.

What Can Claude Do?

Write & Create
  • Draft emails, reports, articles
  • Write and debug code
  • Create presentations
Analyze & Reason
  • Summarize long documents
  • Analyze data and trends
  • Solve math problems
Research & Learn
  • Answer complex questions
  • Explain technical concepts
  • Search the web (Research mode)
Understand Images
  • Describe photos and diagrams
  • Extract text from images
  • Analyze charts and graphs

What Claude Cannot Do

  • Generate, edit, or create images (understanding only)
  • Access the internet in real-time (unless using web search tool)
  • Remember previous conversations (unless using Projects/memory)
  • Identify or name people in images
  • Provide medical diagnosis or legal advice as a professional

Who Made Claude?

Anthropic was founded with a mission to build AI that is safe, beneficial, and understandable. Their core belief: AI's impact could rival the industrial revolution, and they want to make sure it goes well. Anthropic's safety research includes mechanistic interpretability (understanding how AI thinks internally), scalable oversight (using AI to supervise AI), and Constitutional AI (training with principles rather than just human feedback).

Section 04How Claude Works (Under the Hood)

What is an LLM?

A Large Language Model is a neural network trained on vast amounts of text data. It learns patterns in language and generates text by predicting the most likely next token, one at a time. Claude uses the Transformer architecture with self-attention mechanisms.

Key Concepts

ConceptWhat It Means
TokenThe smallest unit Claude processes. ~4 characters or ~0.75 words. "Hello world" = ~2 tokens.
Context WindowClaude's "working memory" — everything it can reference in one conversation. 1M tokens for most models. NOT the same as training data.
TemperatureControls randomness. 0 = deterministic (same answer every time). 1 = creative/varied. Default varies by model.
System PromptHidden instructions that set Claude's behavior, role, and constraints. Users don't see it. Highest priority.
ThinkingClaude can reason step-by-step before answering. Called "adaptive thinking" on newer models. Improves quality for complex tasks.
HallucinationWhen Claude generates confident but factually incorrect information. Always verify important facts.
Knowledge CutoffClaude's training data has a cutoff date. It doesn't know about events after that date (unless using web search).
NondeterminismSame prompt can produce different outputs each time — by design. Set temperature=0 for most consistent results.

How a Conversation Works

Flow1. You send a message (user turn) 2. Claude receives: system prompt + all previous messages + your new message 3. Claude generates a response token by token (autoregressive) 4. The response is added to conversation history 5. On next turn, Claude sees everything above + your new message 6. Context window fills up over time → quality may degrade (context rot)
Important Claude does NOT remember previous conversations. Each new conversation starts fresh. Use Projects to persist context, or paste key information at the start of a new conversation.

Section 05Writing Effective Prompts

The Golden Rule

Show your prompt to a colleague with minimal context. If they'd be confused, Claude will be too.

Four Elements of an Effective Prompt

ElementWhat It DoesExample
ContextBackground info Claude needs"You are helping a marketing team at a SaaS startup..."
RoleWho Claude should act as"You are a senior data analyst with 10 years of experience"
TaskWhat you want Claude to do"Analyze these survey results and identify the top 3 trends"
FormatHow the output should look"Present as a table with columns: Trend, Evidence, Impact"

Before & After Examples

Vague Prompt

Write something about our product.

Effective Prompt

You are a B2B copywriter. Write a 200-word product description for our project management tool targeting engineering teams. Highlight: real-time collaboration, GitHub integration, and sprint planning. Tone: professional but approachable.

Five Core Techniques

  1. Be clear and direct — Specific instructions, desired format, constraints
  2. Add context and motivation — Explain WHY, not just WHAT. Claude generalizes from the reasoning.
  3. Use examples (few-shot) — 3-5 examples of expected input/output. Wrap in <example> XML tags.
  4. Structure with XML tags — Use <instructions>, <context>, <input> to separate sections clearly.
  5. Give Claude a role — Set it in the system prompt. Even one sentence makes a big difference.

Prompt Template

Template<role>You are a financial analyst specializing in tech startups.</role> <context> The user will provide quarterly revenue data for a SaaS company. </context> <instructions> 1. Calculate quarter-over-quarter growth rate 2. Identify the strongest and weakest quarters 3. Provide a one-paragraph forecast for the next quarter </instructions> <format> Return results as a table, followed by the forecast paragraph. </format> <input> Q1: $1.2M, Q2: $1.5M, Q3: $1.4M, Q4: $1.9M </input>

CERRS Mnemonic

Remember the 5 Principles

Clear and direct instructions • Examples (3-5, diverse) • Role in system prompt • Reasoning context (explain WHY) • Structure with XML tags

Thinking / Reasoning

When thinking is active, Claude works through the problem in its own words before answering — like showing its work on a math test. This is called adaptive thinking on Claude 4.7+ models. You can steer it with the effort parameter:

  • low — Quick, minimal thinking (fastest)
  • medium — Balanced (default for Opus 5.5)
  • high — Deep reasoning (default for Fable 5.1 and Sonnet 5)

Section 07Vision & Multimodal

Claude can understand images — but it cannot generate, edit, or create them.

CapabilityDetails
FormatsJPEG, PNG, GIF, WebP (animations not supported — first frame only)
Max size10 MB per image (API), 8000 x 8000 px max dimensions
Max per requestUp to 600 images (1M context models)
Token costceil(width/28) × ceil(height/28) visual tokens. Each 28×28 pixel patch = 1 token.
Image sourcesBase64, URL, or file_id (Files API)
PDFsText + visual content extraction supported
Best Practice Place images before text in your message for best results. Use the Files API for images you'll reuse across turns.

What Claude CAN'T Do with Images

  • Cannot identify or name real people
  • Cannot determine if an image is AI-generated
  • May struggle with very small (<200px), blurry, or rotated images
  • Approximate spatial reasoning and counting

Section 08Tool Use & Agents

What is Tool Use?

Tool use (function calling) lets Claude call functions that you define. Claude decides when to call a tool based on the user's request, then returns a structured call for you to execute.

How It Works

The Loop1. You define tools (name, description, input schema) 2. User asks a question 3. Claude decides to call a tool → returns tool_use block 4. Your code executes the tool 5. You send the result back as tool_result 6. Claude uses the result to answer (or calls more tools) 7. Loop continues until Claude returns stop_reason: "end_turn"

Types of Tools

Client-Side (You Execute)
  • Your custom functions
  • Bash — shell commands
  • Text Editor — file manipulation
  • Computer Use — desktop control
  • Browser Use — web interaction
  • Memory — cross-conversation storage
Server-Side (Anthropic Executes)
  • Web Search — $10/1K searches
  • Web Fetch — no extra cost
  • Code Execution — sandboxed Python
  • Advisor — consult smarter model
  • Tool Search — discover from thousands

What is an Agent?

An agent is Claude + tools + a loop. Instead of answering in one shot, it autonomously plans, calls tools, checks results, and iterates until the task is complete. Claude Code is an example of an agent — it reads your codebase, edits files, runs tests, and commits code.

MCP (Model Context Protocol)

MCP is an open standard for connecting Claude to external tools and data sources — like a universal plugin system. You can connect Jira, Slack, Google Drive, databases, and any custom API via MCP servers.

Section 10Pricing & Tokens

How Pricing Works

You pay per token — separately for input (what you send) and output (what Claude generates). Output tokens are more expensive than input (typically 5x).

Sonnet 5$2$10$1 / $5

Cost-Saving Strategies

Prompt Caching

Cache repeated prompt prefixes. Cache hit = 10% of input cost (90% saving). Pays off after just 1 reuse.

Batch API

Process requests asynchronously for 50% discount. Perfect for evals, data processing, bulk tasks.

Model Routing

Use Haiku ($1) for simple classification, Sonnet ($2) for general tasks, Opus ($4) only for complex work.

Shorter Prompts

Remove redundant instructions. Output tokens cost 5x input, so invest in prompts that produce shorter, targeted outputs.

Token Math

  • 1 token ≈ 4 characters ≈ 0.75 words (English)
  • 1,000 tokens ≈ 750 words ≈ 1.5 pages of text
  • 1M tokens ≈ 555,000 words ≈ 4-5 novels
  • A typical email ≈ 200-400 tokens
  • A 10-page report ≈ 5,000-7,000 tokens

Section 11Safety & Data Privacy

Anthropic's Approach

  • Data is never used for model training without your express permission
  • Zero Data Retention (ZDR) available — Anthropic doesn't store your prompts or responses for eligible features
  • HIPAA readiness available for healthcare use cases
  • Claude has built-in safety classifiers that can decline harmful requests

Best Practices

  • Don't share sensitive data unnecessarily — redact PII before pasting
  • Always verify critical outputs — Claude can hallucinate
  • Don't rely on Claude for medical diagnosis, legal advice, or safety-critical decisions without expert review
  • Be transparent about AI use with end users
  • API keys: Set expiration, keep out of source code, use environment variables

Pro Tips

Iterate, Don't Restart

If the first response isn't perfect, tell Claude what to fix: "Make it shorter" or "Add more detail to point 2." Don't rewrite the whole prompt.

Use Projects for Context

Upload company docs, style guides, and product info to a Project. Every conversation in that project will have access to this knowledge.

Ask for Multiple Options

"Give me 3 different approaches to..." then pick the best one and refine it. Better than hoping for perfection on the first try.

Verify Important Facts

Claude can be confidently wrong. Always cross-check critical facts, dates, URLs, and citations against authoritative sources.
