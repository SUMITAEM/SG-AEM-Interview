Authentication System

The site is fully gated behind Firebase Authentication. Users must sign in before accessing any content.

Supported Login Methods

  • Google Sign-In — One-click login via Google popup (recommended for users)
  • Email/Password — Traditional sign-up and sign-in with email and a password (min 6 chars)

How It Works

1
User visits the site — A full-screen login overlay blocks all content.
2
User signs in — Via Google or email/password.
3
Firebase verifies — Auth state listener detects the signed-in user.
4
Content unlocks — Overlay fades out, app becomes visible, user profile shows in sidebar (desktop) or floating avatar (mobile).
5
User data saved — Name, email, login count, and timestamp stored in Firestore.

Custom Events Tracked

Event: topic_viewed

Fires every time a user navigates to a topic.

Parameters: { topic_id: "t1", topic_title: "AEM Architecture" }

Event: quiz_answered

Fires when a user answers an MCQ.

Parameters: { topic_id: "t1", question: 3, correct: true }

Event: login

Fires on successful authentication.

Parameters: { method: "google" | "email" }

Key Metrics to Watch

  • Daily Active Users (DAU) — How many unique users visit per day
  • Session Duration — Average time spent studying
  • Top Topics — Which topics get the most views (demand indicator)
  • Quiz Accuracy — Correct vs incorrect ratio per topic (difficulty indicator)
  • Retention — Users who come back within 7 days

Note: Google Analytics takes 24-48 hours to populate full reports. The Realtime view works immediately.

Firestore Security Rules

Currently in test mode (open for 30 days). Before it expires, apply these production rules:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId} {
      allow read, write: if request.auth != null
                         && request.auth.uid == userId;
    }
  }
}

Apply at: Firestore → Rules

2
GitHub Actions runs — Copies HTML as index.html, uploads as Pages artifact.
3

Manual Re-deploy

Go to Actions tab → Click latest run → Re-run all jobs.
